# Simple Interest Calculator

## Project Name
Simple Interest Calculator (Bash)

## Description
This project is a Bash script that calculates simple interest based on user input.
The user enters the principal amount, the rate of interest, and the time period,
and the script displays the simple interest.

## Formula
Simple Interest = (Principal x Rate x Time) / 100

- **Principal (P):** the initial amount of money
- **Rate (R):** the annual rate of interest, in percent
- **Time (T):** the time period, in years

## How to run
1. Clone the repository:

       git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git
       cd YOUR_REPO_NAME

2. Make the script executable:

       chmod +x simple-interest.sh

3. Run the script:

       ./simple-interest.sh

## Example
Input:

    Enter principal amount: 1000
    Enter rate of interest (%): 5
    Enter time period (years): 2

Output:

    Simple Interest = 100.00
